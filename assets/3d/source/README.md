# Canonical 3D sources

Place master Greenways/Hara 3D assets here. The initial import mirrors the five full-resolution logo GLBs from `greenways-ai/greenways-ai.github.io` at commit `b1b385dba7e757f88f715db5e69e229b631bc7aa`:

- `greenways-3d-logo.glb`
- `greenways-os-logo.glb`
- `hestia-logo.glb`
- `historia-3d-logo.glb`
- `hodos-3d-logo.glb`

`manifest.json` records the pinned origin, byte size, and SHA-256 of each hydrated source. Web-ready model variants and generated PNG/WebP logo images remain in their publishing repositories.
