Hara is Lisp

One shape. A great deal of range.

The operation comes first. Parentheses hold a computation, vectors hold ordered values, and maps name facts. That small reading model continues from the first expression into a complete program.

Four reading rules Operation first.

Code remains ordinary structure: something the runtime, tools, tests, and people can inspect without translating it into a second model.

Measured in the open

Fast is a result, not a tagline.

Hara publishes the code, environment, timing boundaries, raw samples, and expected checksums behind every reference result. The full table remains visible—including the runtimes that are faster.

01 · Equivalent work

Eight verified algorithms

Arrays, persistent data, recursion, backtracking, branching, range processing, and matrix work share expected results across runtimes.

02 · Honest timing

Preparation is not execution

Startup, preparation, first invocation, warm-up, and steady-state execution are recorded separately where the runtime supports them.

03 · Reproducible

Follow the evidence

Machine details, toolchain versions, source revisions, commands, raw samples, and checksums are committed alongside the report.
